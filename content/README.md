# محتوى الموقع

نصوص وبيانات تُبنى منها صفحات الموقع. بعد أي تعديل هنا شغّل `npm run build` ثم `npm run check`.

| الملف | ماذا فيه |
|---|---|
| `page-translations.json` | نصوص الصفحات الأساسية بالعربي والإنجليزي، وكل نص مربوط بعلامة `WATHBA_COPY` في القالب العربي |
| `product-training.js` | أدلة المعدات الموسعة: الجمهور والعضلات والتدرجات والحصة النموذجية والأخطاء والتركيب والأسئلة |
| `product-education.js` | التعريف المختصر لكل معدة |
| `product-facts.json` | مواصفات المنتجات المؤكدة |
| `product-groups.json` | تجميع المنتجات للبيانات المنظمة |
| `academy-guides.js` | أدلة الأكاديمية الستة المولّدة |
| `category-content.js` | نصوص صفحات الفئات |
| `jump-rope-content.js` | محتوى منتج ودليل حبل القفز |
| `site-identity.json` | هوية وثبة في البيانات المنظمة |

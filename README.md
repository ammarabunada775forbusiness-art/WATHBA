# WATHBA

موقع معدات وأكاديمية وثبة، بالعربية والإنجليزية. لكل صفحة رابط مستقل؛ العربية هي النسخة الافتراضية.

للبناء المحلي، شغّل من مجلد المشروع (Node.js 18 أو أحدث، دون تثبيت حزم):

```sh
node scripts/build-product-pages.js
```

يشمل البناء صور المنتجات والمعارض والصفحات الأساسية الثماني وروابط اللغات وإصدارات الملفات المشتركة. تبقى ملفات HTML الناتجة جاهزة للاستضافة الثابتة مباشرة.

- [الصور المرقمة وأوامر الفحص](PRODUCT-IMAGES.md)
- [ربط الدومين وتفعيل خريطة المواقع](SEO-LAUNCH.md)

نصوص ترجمة الصفحات الأساسية في `scripts/page-translations.json`. لا تحذف تعليقات `WATHBA_COPY` و`WATHBA_SLOT` من القوالب العربية؛ يستخدمها البناء لتحديث النصوص والمنتجات مع الحفاظ على التخطيط.

# وثبة: إطلاق الدومين ومتابعة SEO

النسخة الحالية مبنية كـHTML ثابت بالعربية والإنجليزية: 8 صفحات أساسية، و28 صفحة للمنتجات الـ14، و8 صفحات للأكاديمية. صفحات الخطأ والقالب القديم غير مخصصة للفهرسة. التنسيق والخطوط والأيقونات محلية؛ لا يعتمد ظهور المحتوى على JavaScript.

## عند ربط الدومين الحقيقي

1. تأكد من فتح الموقع عبر HTTPS واختر النسخة الأساسية من الدومين (`www` أو بدونها). اضبط تحويل النسخ الأخرى على الاستضافة.
2. شغّل `node scripts/publish-seo.js https://YOUR-ACTUAL-DOMAIN` بعد استبدال الرابط بدومينك النهائي. الأداة تضيف canonical وhreflang وOpen Graph URL، وبيانات WebSite وOrganization للصفحة الرئيسية وBreadcrumbList للأدلة والمنتجات. وتكتب `public/sitemap.xml` ومرجعه في `public/robots.txt`، باستثناء الصفحات غير المخصصة للفهرسة.
3. تحفظ الأداة الدومين في `scripts/seo-origin.json`. بعد ذلك يعيد `node scripts/build-site.js` إنشاء بيانات SEO تلقائيًا كل مرة؛ لن تضيع عند إعادة بناء الصفحات.
4. شغّل `npm run build` وانشر مجلد `public/` عبر إعدادات `vercel.json`، ثم أضف ملكية الدومين في Google Search Console. أرسل `/sitemap.xml` وافحص أمثلة عربية وإنجليزية باستخدام URL Inspection وRich Results Test.
5. اضبط صفحة الخطأ على استجابة HTTP 404، والتحويل الدائم للروابط القديمة على مستوى الاستضافة عندما تدعم ذلك. تحويل المتصفح القديم متوفر حاليًا في `product.html?id=...`.

لا توجد خريطة مواقع بدومين تجريبي في المستودع. الاختبارات تستخدم نسخة مؤقتة منفصلة.

## قبل البيع الفعلي

- أضف صورًا حقيقية للمعدات في المسارات المحددة في `public/assets/js/products-data.js`. يمكن إضافة `gallery` كمصفوفة مسارات صور؛ يظهر معرضها عند وجود الملفات. الرسومات الموجودة حاليًا توضيحية وموسومة كذلك.
- أكّد القياسات والخامات ومتطلبات التثبيت والأسعار والتوفر، ومدة التصنيع والتوصيل والتركيب وشروط الاسترجاع الفعلية. لا تضف معلومات غير مؤكدة كحقائق.
- أضف بيانات Product/Offer عندما تتوفر أسعار وعروض فعلية منشورة للزائر. لا تستخدم سعرًا صفريًا أو تقييمات أو مخزونًا افتراضيًا.
- راجع أدلة التمرين مع مختص مؤهل، ثم أضف صورًا أو فيديوهات توضح الأداء الصحيح واسم المراجع وتاريخ المراجعة الحقيقي عند توفره.

## بعد الإطلاق

تابع الفهرسة وأخطاء الصفحات والأداء على الهاتف وCore Web Vitals والبحث الفعلي في Search Console. استعمل الأسئلة التي تظهر فعلًا لتطوير أدلة مفيدة، مثل الحلقات والديبس واختيار تجهيز المنزل. قوّة المحتوى لا تُقاس بتجميع أكبر عدد من الكلمات أو إنشاء صفحات متشابهة. يمكن دراسة Google Business Profile حسب طبيعة النشاط وأهليته عند إطلاقه.

الفحوص المحلية تؤكد سلامة الواجهات والروابط وتوليد البيانات، ولا تثبت فهرسة Google أو ترتيبًا معينًا أو درجات أداء على استضافة لم تُختبر بعد.
